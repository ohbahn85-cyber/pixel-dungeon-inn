# 픽셀 던전 여관: 카이로 슬롯 타이쿤

카이로소프트 감성의 **쿼터뷰(아이소메트릭) 도트 여관**을 운영하는 브라우저 게임입니다. 네 시설(여관, 대장간, 포션 공방, 교역소)에서 재료를 베팅해 슬롯을 돌리고, `[채택]`하거나 `[버리기]`로 마일리지 가루를 모아 영웅과 시설을 키운 뒤 던전에 나갑니다.

- 플레이: [https://ohbahn85-cyber.github.io/pixel-dungeon-inn/](https://ohbahn85-cyber.github.io/pixel-dungeon-inn/)
- 밸런스: [BALANCE.md](BALANCE.md)

## 하는 법

- 맵은 여관 건물 안의 한 공간입니다. 식당·대장간·포션 공방·교역소는 코너에 있고, 바닥을 탭하면 해당 슬롯이 열립니다.
- 슬롯 화면은 **재료, C/B/A/S 확률 막대, 릴, 채택/버리기**만 보여 줍니다. 자세한 설명은 버튼에 잠시 올려 두거나 길게 누르면 됩니다.
- 강화는 실패해도 장비가 부서지지 않고, 그때의 `+`에서 잠깁니다.
- 체력이 45% 아래로 떨어지면 포션을 자동으로 마십니다.
- 슬롯 릴은 종류별 도트 그림입니다. 돌릴 때 흐려졌다가 튕기며 멈춥니다.
- 던전은 4구역(버섯 숲, 수정 동굴, 황금 유적, 용암 성채)이고, 여관에서 원정 표시를 누르면 전투 장면으로 전환됩니다. 각 3웨이브+보스, 전투 중 미니 슬롯, 클리어 후 보상 배율 슬롯(x1.5 / x2 / x3)이 있습니다.
- 목표 페이스: 2구역 약 20–30분, 3구역 약 1–1.5시간, 4구역 보스 약 3–4시간.

## 저장 (v5)

자동 저장은 `IndexedDB`와 `LocalStorage`(`kairo_slot_dungeon_inn_v5`) 두 곳에 하고, 더 최신 `savedAt`을 불러옵니다. 하단 **저장**에서 `.json` 파일로 내보내거나 불러올 수 있습니다. 예전(v1~v4) 세이브는 쓰지 않습니다.
