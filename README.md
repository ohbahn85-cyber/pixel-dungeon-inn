# 🍻 던전 여관: 살아있는 모험가의 쉼터 (Pixel Dungeon Inn — 카이로소프트풍 생활 시뮬 & 층별 원정 개편판)

판타지 던전 입구 옆 여관의 주인이 되어 **한눈에 보이는 여관 전체 픽셀 맵(`480×288`)**을 꾸리고, **고유 이름을 가진 9직업 30명의 영웅 에이전트**가 스스로 걸어다니며 **식사·수면·전리품 거래·포션/장비 쇼핑·의뢰 게시판 파티 결성·층별 던전 자동 전투**를 펼치는 **도트(픽셀) 경영 시뮬레이션 & RPG 웹 게임**입니다.

- **배포 주소 (GitHub Pages)**: [https://ohbahn85-cyber.github.io/pixel-dungeon-inn/](https://ohbahn85-cyber.github.io/pixel-dungeon-inn/)

## 🎮 핵심 시스템 및 주요 특징

### 1. 🏠 한눈에 보이는 여관 전체 맵 & 타일 그리드 에이전트 이동
- **7개 핵심 구역이 한 맵에 배치**:
  1. **🍲 1층 식당 & 🍺 바/주방**: 6개 원목 식탁(12석), 화덕 가마솥, 바 카운터와 스툴
  2. **🛏️ 2층 객실 날개 & ♨️ 온천**: 나무 계단으로 연결된 2층 침대 4개와 지하 마력 온천탕
  3. **⚗️ 포션 가게 코너**: 약초/포션 진열 선반, 절구, 마력 증류기, 룬 무쇠 가마솥, 좌하단 약초밭
  4. **⚒️ 드워프 대장간**: 고열 화로, 강철·미스릴 모루, 룬 숫돌, 담금질 통, 무기 진열대
  5. **💎 거래/시장 가판대**: 줄무늬 천막 매대, 황금 저울, 전리품 상자
  6. **📋 모험가 의뢰 게시판**: 영웅들이 모여 시너지 파티를 결성하는 집결 광장
  7. **🗺️ 던전으로 가는 입구 아치**: 파티가 걸어나가 던전으로 출발하고 귀환하는 석조 아치문
- **격자 경로탐색(BFS/A*) & 픽셀 애니메이션**:
  - 영웅들은 보이는 에이전트로서 벽과 가구를 피해 통로와 계단으로 걸어다니며, 목적지에서 식사·음주·수면(`Zzz`)·망치질·흥정 애니메이션과 아이템/골드 이펙트를 보여 줍니다.
  - 모바일·태블릿(iPad)에서는 **`[🔍 전체 맞춤 보기 / ↔️ 확대 팬 모드]`** 버튼으로 전체 맵을 한눈에 보거나 좌우로 스크롤할 수 있습니다.

### 2. 🎪 플레이어는 무대를 꾸리고, 영웅은 스스로 반응합니다
- **`💎 상점·거래` 탭의 시세 및 품목 설정**:
  - **요리·포션·대장간 장비 판매 설정**: 판매 여부(`ON/OFF`)와 가격 배율(`80% 할인 / 100% 정가 / 125% 할증 / 150% 고급`)을 설정할 수 있으며, 포션별로 개별 판매 등록(`ON/OFF`)을 제어할 수 있습니다.
  - **전리품 매입 설정**: 14종 전리품 재료별 매입 허용(`ON/OFF`)과 일괄 매입 시세(`75% 저가 / 90% 알뜰 / 100% 정가 / 115% 우대`)를 설정할 수 있습니다.
  - **대장간 자율 강화 의뢰**: 영웅이 자기 골드로 대장간에서 안전한 저단계(`+1~+2`) 강화를 자율 의뢰할지 허용(`ON/OFF`)할 수 있습니다.
- **욕구 기반 자율 AI 루프**:
  - 영웅은 **HP, 허기(Hunger), 피로(Fatigue), 개인 골드, 장비 수준, 탐험 의지**에 따라 `부상/피로 회복 → 거래대 전리품 매각 → 대장간/포션 쇼핑 → 식당 식사 → 의뢰 게시판 파티 결성(역할·성격·출신 시너지) → 던전 입구 출발` 루프를 스스로 수행합니다.

### 3. 🎯 영웅 클릭 → 상태 확인 & 특정 행동 직접 지시
- 여관 맵 위의 영웅을 클릭/탭(또는 `🦸 영웅` 탭에서 `[🎯 상태 확인 & 행동 지시]` 클릭)하면 **영웅 상태 & 지시 패널**이 열립니다.
- **확인 가능 정보**: 이름·칭호·직업/역할, 레벨/XP, `ATK/DEF/AGI/INT/HP/LUK` 및 전투력, **HP·허기·피로·개인 골드**, 4슬롯 장비, 성격·출신, **현재 의도(`"거래대로 이동 중"`, `"1층 식당에서 식사 중"`, `"초록 슬라임 동굴 2/3층 탐험 중"` 등)**, 소속 파티.
- **플레이어 직접 지시**:
  - `🍲 식당 가서 식사`, `🍺 바에서 에일`, `🛏️ 2층 객실 휴식`, `💎 거래대 전리품 매각`, `⚒️ 대장간 장비 장착`, `📋 게시판 파티 결성`, `⚗️ 특정 포션 사러 가기`, `🚀 지정 던전 출발`을 지시할 수 있습니다.
  - 지시는 **그 행동이 끝날 때까지** 자율 AI를 덮어쓰며, 완료 후 자동으로 자율 AI로 복귀합니다. 언제든 **`[✖ 지시 취소]`**로 즉시 자율 행동으로 되돌릴 수 있습니다.

### 4. ⚔️ 카이로소프트풍 층별 던전 탐험 & 자동 전투 뷰
- 여관 맵 바로 아래의 **실시간 던전 층별 탐험 뷰(`480×136`)**에서 원정대의 던전 진행을 실시간으로 감상할 수 있습니다.
- **층별 전진 및 몬스터/보스 자동 전투**:
  - 파티가 던전 테마별(`동굴·야영지·그림자 숲·마법탑·광산·성소·화산`) 복도를 전진하며 각 층의 몬스터 및 최종 층 보스와 자동 전투를 벌입니다.
  - 전열(탱커)·중열(딜러/지원)·후열(힐러) 진형, 공격 모션, 데미지/치유 숫자, 개별 HP바가 표시됩니다.
  - 층 클리어 시 **전리품 드랍 아이콘**이 눈에 보이게 튀어나오며, 실패 시에는 부상 상태로 후퇴해 여관 입구로 돌아와 치료부터 받는 루프가 이어집니다.
  - 동시에 여러 파티가 탐험 중일 때는 상단 파티 탭(미니 진행 바 포함)을 눌러 원하는 원정대를 자세히 관찰할 수 있습니다.

### 5. 💬 한국어 말풍선 & 더 부드럽고 따뜻한 도트 그래픽
- **상황·성격별 한국어 말풍선**:
  - 영웅 머리 위에 배고픔, 식사 만족, 비싼 물가/낮은 매입가 불만, 할인 칭찬, `+강화` 성공 자랑, 출정 전 다짐, 동료와의 실랑이/호흡 대사가 성격(`다혈질·신중·명랑·고독·탐욕·자만·충직·자비·장난기·용감`)에 맞는 말투로 표시됩니다.
- **따뜻하고 아늑한 저채도 팔레트**:
  - 픽셀 도트의 선명함(`image-rendering: pixelated`)은 그대로 유지하면서, 눈이 편안한 따뜻한 원목·양피지·세이지·허니골드 톤과 부드러운 다크브라운 외곽선으로 그래픽을 개편했습니다.

## 🛠️ 로컬 실행, 빌드 및 밸런스 시뮬레이션

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 프로덕션 정적 빌드 (tsc 타입체크 && vite build -> dist/ 생성)
npm run build

# 4. 4시간(14,400초) 헤드리스 밸런스 시뮬레이션 실행 (scripts/simulate-last.json 갱신)
npm run simulate
```
