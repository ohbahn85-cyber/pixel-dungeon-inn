판타지 던전 입구 옆 여관의 주인이 되어 **화면 대부분을 차지하는 살아있는 여관 전체 픽셀 맵(`480×288`)**을 경영하고, **고유 이름을 가진 9직업 30명의 영웅 에이전트**가 스스로 걸어다니며 **식사·수면·전리품 거래·포션/장비 쇼핑·의뢰 게시판 파티 결성·분기형 던전 원정**을 펼치는 **도트(픽셀) 여관 경영 시뮬레이션 & RPG 웹 게임**입니다.

- **배포 주소 (GitHub Pages)**: [https://ohbahn85-cyber.github.io/pixel-dungeon-inn/](https://ohbahn85-cyber.github.io/pixel-dungeon-inn/)

## 🎮 v4 핵심 시스템 및 주요 특징

### 1. 🗺️ 여관 맵 중심(Map-Dominant) 레이아웃 & 서랍형(Drawer) UI
- **여관 전체 맵이 화면의 중심**:
  - 7개 구역(`🍲 1층 식당 & 바`, `🛏️ 2층 객실 & 온천`, `⚗️ 포션 가게`, `⚒️ 드워프 대장간`, `💎 거래 가판대`, `📋 의뢰 게시판`, `🗺️ 던전 입구 아치`)이 한 맵에서 살아 움직입니다.
  - 상단 창문과 조명, 횃불·창가 광원이 **하루 시간대(`🌅 아침 → ☀️ 낮 → 🌆 저녁 → 🌙 밤`)**에 따라 자연스럽게 변화합니다.
- **기본 닫힘 상태의 오버레이 서랍**:
  - **영웅 상세·명령 서랍(`#hero-inspector-panel`)**은 기본 닫힘 상태로 시작해 맵을 가리지 않으며, 맵 위에서 영웅을 클릭/탭했을 때만 우측 반투명 오버레이 서랍으로 열립니다(`✕ 닫기` 또는 빈 공간 클릭으로 즉시 닫힘).
  - 하단 7개 도크 버튼(`🏆 등급·목표`, `💎 상점·거래`, `🏰 여관·직원`, `⚗️ 포션가게`, `⚒️ 대장간`, `🦸 영웅·던전`, `📊 통계·장부`)을 누르면 하단 슬라이드업 서랍이 열리며, 같은 탭을 다시 누르거나 `✕ 닫기`를 누르면 맵 전체 시야로 돌아갑니다.
  - 원정대가 출발하면 **던전 원정 오버레이 패널(`480×176`)**로 실시간 분기 방 탐험을 감상할 수 있고, 언제든 **`[🏠 여관 맵으로 돌아가기]`** 버튼으로 여관 맵과 원정 화면을 전환할 수 있습니다.

### 2. 🏆 상단 HUD 상시 노출 여관 등급 목표 (Lv.1 ~ Lv.8)
- 상단 얇은 HUD 바에 **보유 골드, 오늘 순이익, 일일 고정비(급여+유지비), 현재 일차·시각·낮/밤, 여관 등급, 그리고 다음 등급 승급 목표 체크리스트**가 항상 표시됩니다.
- **`Lv.1 변두리 작은 여관` → `Lv.8 전설의 왕국 최고 여관`**까지 8단계의 명확한 다중 목표(특정 던전 클리어, 시설/직원 레벨, 영웅 합류 수, 포션/장비 제작, 일일 순이익)와 최종 목표(**`🐉 고대 용왕의 화산 둥지` 토벌**), 그리고 9종의 보너스 선택 과제가 제공됩니다.

### 3. 💰 초당 자동 골드(GPS) 완전 제거 & 행동 기반 수입 · 일일 정산
- **초당 패시브 골드(`0 G/s`) 완전 폐지**: 가만히 있어도 초당 골드가 오르던 방치형 공식을 완전히 제거했습니다.
- **오직 영웅·손님의 실제 행동으로만 골드 획득**:
  - `🍲 식당 요리·바 에일 판매`, `🛏️ 2층 객실·온천 휴식료`, `⚗️ 포션 판매`, `⚒️ 대장간 장비 판매 및 +강화 수수료`, `🍺 일반 손님 좌석 접대 수입`, `💎 전리품 감정·유통 마진`에서만 골드를 법니다.
- **4분(240초) 하루 주기 & 일일 결산 보고서**:
  - 매일 밤이 끝나면 고용 직원 일일 급여(`wages`)와 시설 유지비(`upkeep`)가 정산되며 **일일 결산 모달**이 표시됩니다.
  - **`📊 통계·장부`** 탭에서 최근 일차별 수입·운영 지출·순이익 막대그래프와 항목별 상세 장부를 확인할 수 있습니다.

### 4. ⚔️ 더 풍부해진 분기형 던전 탐험 · 9직업 전용 전투 스킬 · 영웅 개성
- **7개 테마 던전 & 2갈래 분기 방 그래프**:
  - 각 층마다 `⚔️ 일반 교전`, `🎁 보물 방`, `⚙️ 함정 복도`, `⛺ 모닥불 쉼터`, `❓ 기묘한 만남(2~3지선다 한국어 선택 이벤트)`, `💀 정예 수문장`, `👑 보스 알현실` 분기 노드를 탐험합니다.
- **몬스터 5종 행동 패턴 & 9직업 고유 스킬**:
  - 몬스터의 `돌진·원거리·맹독·군집·중장갑` 전술 태그와 9직업 영웅의 고유 전투 스킬(`방패 강타`, `성광의 방패`, `대지 분쇄`, `그림자 기습`, `관통 일제사격`, `별빛 비전 폭격`, `광란의 회전베기`, `성스러운 치유광`, `전술 독려 사격`)이 투사체·광선·방벽 도트 이펙트로 연출됩니다.
- **맵 위에서도 드러나는 영웅 성격·직업 특성**:
  - 여관 맵 위 영웅 발밑의 역할별 컬러 링(`🛡️ 탱커 / ⚔️ 딜러 / 💚 힐러 / 🎺 지원가`), 머리 위 직업 아이콘 배지, 성격에 따른 이동 속도 및 한국어 말풍선 빈도 차이가 구현되어 있습니다.

## 💾 데이터 저장 (v4), 구세이브 마이그레이션 및 일차 기반 오프라인 정산

- **자동 저장 (`localStorage`)**: `pixel_dungeon_inn_save_v1` (`SaveData.version = 4`)에 자동 저장됩니다.
- **v1~v3 → v4 마이그레이션 안내**: 구버전(v1~v3) 세이브 감지 시 v4 경제·목표 개편 안내 모달을 띄워 **새 게임 시작(권장)** 또는 **기존 세이브 이어하기**를 선택할 수 있습니다.
- **일차 기반 오프라인 정산**: 재접속 시 경과 시간(최대 8시간)을 일차 단위로 시뮬레이션하여 오프라인 동안의 행동 수입, 급여·유지비 지출, 순이익, 던전 클리어, 제작 및 치료 내역을 보고합니다.

## 🛠️ 로컬 실행, 빌드 및 밸런스 시뮬레이션

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 프로덕션 정적 빌드 (tsc 타입체크 && vite build -> dist/ 생성)
npm run build

# 4. 4시간(14,400초 = 60일) 헤드리스 밸런스 시뮬레이션 실행 (scripts/simulate-last.json 갱신)
npm run simulate
```
