# 🍻 던전 여관: 모험가의 쉼터 (Pixel Dungeon Inn — 순환 경제 & 영웅 원정대 확장판)

판타지 던전 입구 옆 여관의 주인이 되어 모험가 손님을 대접하고, **고유 이름을 가진 9직업 30명의 영웅 원정대**를 던전에 파견하여 **전리품 매입 → 포션 조제 & 대장간 장비 단조(+강화) → 영웅 구매 및 버프 → 상위 던전 돌파**로 이어지는 순환 경제를 경영하는 **도트(픽셀) 그래픽 방치형 경영 타이쿤 & RPG 웹 게임**입니다.

- **배포 주소 (GitHub Pages)**: [https://ohbahn85-cyber.github.io/pixel-dungeon-inn/](https://ohbahn85-cyber.github.io/pixel-dungeon-inn/)
- **밸런스 및 시뮬레이션 상세 문서**: [BALANCE.md](file:///workspace/code/pixel-dungeon-inn/BALANCE.md)

## 🎮 핵심 시스템 및 주요 특징

### 1. 🔄 골드와 전리품의 순환 경제 (Circular Economy)
1. **영웅의 던전 탐험**: 소속 영웅들이 던전을 공략해 **전리품 재료(14종)**와 개인 골드, 경험치를 획득합니다.
2. **전리품 매입 (`💎 거래` 탭)**: 플레이어(여관 주인)가 골드로 영웅의 전리품을 매입하면 재료는 여관 창고에 쌓이고, 영웅은 현금을 얻습니다.
3. **영웅의 자율 소비 (여관 수입)**: 현금을 확보한 영웅들은 탐험 전이나 부상 시 스스로 **여관 요리·객실 숙박·포션 가게 물약·대장간 장비**를 구매하여 플레이어에게 골드 수입을 안겨 줍니다.
4. **시설 & 레시피 발전**: 플레이어는 매입한 재료와 골드로 메뉴·객실·포션 도구·대장간 화로/모루를 업그레이드하고 더 강력한 포션과 장비를 공급합니다.
5. **교착 방지 안전장치**: 플레이어 골드가 부족해 45초 동안 전리품을 사지 못하면 영웅이 행상인에게 저가(50%)로 자동 매각해 현금을 확보하고 여관에 수수료와 샘플 재료를 남깁니다. 기존 일회성 방문 손님 서빙/GPS 기본 수입도 상시 유지됩니다.

### 2. 🦸 고정된 이름 있는 고유 영웅 (9직업 30명) & 성격·출신·파티 시너지
- **익명 대량 고용 없음**: 모든 영웅은 고유 ID, 한국어 이름, 칭호, 배경 이야기, 도트 컬러 팔레트를 지닌 **30명의 고정 캐릭터**로 구성됩니다.
- **시작 파티 4명**: **가릭**(강철 전사/탱커), **엘레나**(성전 사제/힐러), **카엘**(그림자 도적/딜러), **아린**(유랑 모험가/지원가)으로 시작하며, 여관 평판과 특정 던전 클리어 조건을 만족할 때마다 나머지 26명이 차례로 여관에 합류합니다.
- **9개 직업과 전용 장비 제한**:
  - `강철 전사`, `태양 성기사`, `그림자 도적`, `엘프 명궁`, `별빛 마법사`, `성전 사제`, `광전사`, `난쟁이 중갑병`, `유랑 모험가`
- **성격 궁합 & 상극 충돌 (10종 성격)**:
  - `충직+용감`(**결속의 선봉 +6%**), `명랑+자비로움`(**따스한 동행 +5%**), `신중+충직`(**철벽의 진형 +5%**) 등 호궁합 쌍은 성공률과 스탯을 높여 줍니다.
  - 반면 `다혈질⚡신중`(**작전 불화 -6%**), `탐욕⚡충직`(**전리품 분배 다툼 -5%**), `자만⚡자만`(**자존심 대립 -8%**) 등 상극 쌍은 한 파티에 넣으면 성공률 페널티가 발생합니다.
- **출신 배경 패시브 & 동향 세트 시너지 (8종 출신)**:
  - `북방 설원 부족`, `천년 엘프 숲`, `왕도 귀족 가문`, `왕도 뒷골목 빈민가`, `대성당 사원 고아원`, `드워프 강철 산맥`, `별빛 고대 마탑`, `대륙 유랑 상단`마다 선호 던전 성공률(+6~8%)과 고유 패시브가 있으며, 같은 출신 2인 이상 편성 시 **동향 세트 시너지(+5~6%)**가 추가됩니다.

### 3. 🗺️ 7종 던전 & 출발 전 파티 시너지 미리보기
- 요구 능력치 프로필이 서로 다른 7개 던전:
  1. **🟢 초록 슬라임 동굴** (기초 균형)
  2. **👺 고블린 약탈자 소굴** (근접 ATK·DEF)
  3. **🌲 안개 그림자 숲** (민첩 AGI·행운 LUK 특화)
  4. **🔮 폐허가 된 별빛 마법탑** (마법 지력 INT 특화)
  5. **⛏️ 버려진 드워프 미스릴 광산** (방어 DEF·체력 HP 특화)
  6. **🏛️ 심연의 고대 성소** (INT·AGI·DEF 복합)
  7. **🐉 고대 용왕의 화산 둥지** (전 능력치 종합 극한)
- **출발 전 시너지 미리보기 패널**: 파견 전 선택한 파티의 **역할 삼각 진형(+10%) 또는 힐러/탱커 부재 경고**, **성격 궁합/충돌 목록과 수치**, **출신 패시브 및 세트 시너지**, **최종 예상 성공률(8%~95%)**을 실시간으로 보여 주며, **`[⚡ 최적 시너지 파티 자동 편성]`** 버튼으로 손쉽게 최적 파티를 꾸릴 수 있습니다.

### 4. ⚗️ 포션 가게 (`⚗️ 포션` 탭)
- **도구·시설 6종**: `약초 절구와 공이`, `마력 유리 증류기`, `룬 무쇠 연금 가마솥`, `여관 뒤편 약초 정원`(자동 약초 수확 & 캔버스 표시), `전문 연금술 작업실`(동시 제작 큐 최대 3슬롯 확장), `연금술사 벨라 & 비전 마법진`.
- **포션 레시피 8종**: `희석된 약초수`, `초급 치유 물약`, `부상 완치 연고`, `거인의 괴력 비약`, `질풍의 민첩 비약`, `별빛 지혜의 비약`, `미스릴 강철피부 영약`, `용왕의 불멸 종합 영약`.
- 도구·시설 레벨에 따라 조제 성공률이 오르고 시간이 단축되며, 조제 실패 시에도 하위 등급 포션을 부산물로 건질 수 있습니다.

### 5. ⚒️ 대장간 & `+강화` (실패 시 완전 파괴 주의!)
- **도구·시설 5종**: `드워프 고열 화로`, `강철·미스릴 모루`, `룬 마력 숫돌`, `마력 오일 담금질 통`, `대장장이 장인 토르가`(단조 슬롯 최대 3개 확장).
- **영웅별 4개 장비 슬롯 & 5단계 희귀도**:
  - 모든 영웅은 **무기 · 방어구 · 보조/방패 · 장신구** 4개 슬롯을 가집니다.
  - 희귀도: **일반(기본) / 고급 / 희귀 / 영웅 / 전설**. 직업별로 착용 가능한 무기와 방어구 종류가 구분됩니다.
- **🔥 `+1 ~ +15` 강화와 완전 파괴 위험**:
  - 제작된 장비에 골드와 재료를 들여 `+강화`를 시도하면 스탯이 크게 상승합니다.
  - 성공 확률은 **`+0→+1 (95%)`**, **`+3→+4 (58%)`**, **`+6→+7 (16%)`**, **`+9→+10 (2.0%)`**, **`+14→+15 (0.20%)`**로 극단적으로 가파르게 하락합니다.
  - **⚠️ 강화에 실패하면 해당 아이템(`+강화` 수치와 원본 장비 모두)이 완전히 파괴되어 소멸**합니다! 강화 시도 전 반드시 파괴 위험 확인 대화상자가 표시됩니다.
  - 단, 장비가 파괴되더라도 해당 영웅은 즉시 **파괴 불가 기본 장비**로 자동 복귀하므로 던전 탐험이 교착되지 않습니다.

## 🕹️ 플레이 방법

1. **손님 서빙 및 호객**: 캔버스의 손님 말풍선(`!`)을 탭하거나 **`[🍻 직접 서빙 / 호객하기]`** 버튼을 눌러 초기 자금과 여관 평판을 모으세요.
2. **던전 파견 (`🗺️ 던전`)**: 시작 영웅 파티를 선택하고 시너지 미리보기를 확인한 뒤 **`[🚀 원정대 파견하기]`**를 누르세요. **`[🤖 자동 파견: ON]`**을 켜 두면 대기 영웅들이 자동으로 최적 던전에 출정합니다.
3. **전리품 매입 (`💎 거래`)**: 원정대가 가져온 전리품을 **`[전체 일괄 매입]`** 또는 **`[🤖 자동 매입: ON]`**으로 사들이세요.
4. **포션 조제 (`⚗️ 포션`) & 장비 단조 (`⚒️ 대장간`)**: 창고에 쌓인 재료로 포션과 장비를 제작하세요. 영웅들이 자기 골드로 사 가거나 **`🦸 영웅`** 탭에서 직접 지급·장착 및 **`🔥 +강화`**를 시도할 수 있습니다.

## 💾 데이터 저장, v1→v2 마이그레이션 및 오프라인 정산

- **자동 저장 (`localStorage`)**: 브라우저 `localStorage`(`pixel_dungeon_inn_save_v1`, `SaveData.version = 2`)에 5초마다 및 주요 행동 시 자동 저장됩니다.
- **v1 구세이브 마이그레이션**: 기존 v1 저장 데이터(골드·업그레이드·평판만 있던 세이브)를 감지하면 골드·평판·업그레이드를 안전하게 보존한 채 시작 영웅단을 합류시키며, 확인 모달을 통해 **기존 진행 이어받기** 또는 **처음부터 새로 하기**를 선택할 수 있습니다.
- **오프라인 8시간 방치 정산**: 게임을 닫았다가 다시 열면 최대 **8시간** 동안의 기본 수입(GPS), 완료된 던전 탐험, 조제된 포션/단조된 장비, 행상인 안전 매각 내역을 **「다녀왔습니다!」** 모달에서 한눈에 정산받습니다.

## 🛠️ 로컬 실행, 빌드 및 밸런스 시뮬레이션

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 프로덕션 정적 빌드 (tsc 타입체크 && vite build -> dist/ 생성)
npm run build

# 4. 4시간(14,400초) 헤드리스 밸런스 시뮬레이션 실행 (scripts/simulate-last.json 갱신)
npm run simulate
```
