# 🍻 던전 여관: 모험가의 쉼터 (Pixel Dungeon Inn)

판타지 던전 입구 옆 작은 여관의 주인이 되어 모험가들에게 따뜻한 식사와 음료, 포근한 잠자리, 장비 수리를 제공하는 **도트(픽셀) 그래픽 방치형 경영 타이쿤 웹 게임**입니다.

- **배포 주소 (GitHub Pages)**: [https://ohbahn85-cyber.github.io/pixel-dungeon-inn/](https://ohbahn85-cyber.github.io/pixel-dungeon-inn/)

---

## 🎮 게임 소개 및 주요 특징

- **살아 움직이는 픽셀 여관 내부 장면 (`<canvas>`)**:
  - 깜빡이는 벽난로와 보글보글 끓는 스튜 가마솥, 창밖으로 보이는 밤하늘과 던전 석조 아치 입구, 나무 바닥과 카운터, 오크 술통, 2층 객실 계단, 의뢰 게시판, 드워프 대장간, 오르골, 비밀 금고, 마력 온천탕이 코드 기반 픽셀아트로 그려집니다.
- **8종의 개성 넘치는 모험가 손님**:
  - **초보 여행자**, **강철 전사**, **그림자 도적**, **별빛 마법사**, **태양의 성기사**부터 중후반 특수/VIP 손님인 **난쟁이 용병**, **엘프 정찰대장**, **은퇴한 용왕(VIP)**까지 고유한 도트 스프라이트와 재치 있는 대사를 지닌 손님들이 방문합니다.
  - 고급 손님은 식사나 숙박 후 가끔 **던전 전리품**(고블린 금니, 빛나는 마석 조각, 순수한 미스릴 광석, 세계수의 황금 잎사귀, 고대 용왕의 황금 비늘 등)을 팁으로 남깁니다.
- **4대 업그레이드 카테고리 & 직원 고용**:
  - **🍲 메뉴**: 약초 건빵 수프, 화덕 고기 스튜, 드워프 맥아 에일, 달빛 마나 포션, 심연 버섯 스테이크, 용의 숨결 특제 만찬
  - **🛏️ 객실**: 다락방 밀짚 침대, 참나무 2층 침대, 푹신한 양털 객실, 마법 방음 개인실, 왕실 규격 스위트룸
  - **🧑‍🍳 직원**: 견습 메이드 리나, 베테랑 바텐더 브롬, 수석 요리사 고든, 낭만 음유시인 엘리 (고용 시 여관 장면에 직접 등장하여 일하며 자동 서빙 및 초당 골드 증가)
  - **⚒️ 시설**: 모험가 의뢰 게시판, 드워프 간이 대장간, 마법 태엽 오르골, 강철 비밀 금고, 지하 마력 온천탕
- **랜덤 이벤트 & 8비트 레트로 효과음**:
  - 던전 보스 토벌 축하연, 폭우로 인한 손님 행렬, 오늘의 스튜 대성공, 바삭하게 탄 빵 해프닝, 떠돌이 보물 상인 방문 등 재미있는 이벤트가 발생합니다.
  - Web Audio API 합성음을 사용해 외부 음원 파일 없이 레트로 효과음을 재생하며, 상단 버튼으로 언제든 음소거할 수 있습니다.

## 🕹️ 플레이 방법

1. **직접 서빙 및 호객 (클릭 / 탭)**:
   - 여관에 입장한 모험가가 자리에 앉아 머리 위에 **주문 말풍선(`!`)**을 띄우면 해당 손님을 클릭/탭하거나 하단의 **`[🍻 직접 서빙 / 호객하기]`** 버튼을 누르세요.
   - 코인이 튀며 즉시 골드와 평판을 획득하고, 직접 서빙 시 **+25% 친절 보너스**가 적용됩니다.
   - 대기 중인 손님이 없을 때 캔버스나 버튼을 탭하면 여관을 정돈하고 호객하여 소량의 보너스 골드를 얻고 다음 손님이 더 빨리 입장합니다.
2. **업그레이드 구매**:
   - 모은 골드로 우측(모바일은 하단) 탭에서 **메뉴·객실·직원·시설**을 구매하거나 강화하세요. 비용은 레벨에 따라 `기본비용 × 1.15^레벨`로 증가하며 구매 즉시 효과가 적용됩니다.
3. **평판 상승과 해금**:
   - 손님을 대접하고 업그레이드를 진행하면 **여관 평판**이 쌓여 `Lv.1 변두리 작은 여관`부터 `Lv.10 전설의 던전 여관`까지 승급하며 새로운 손님과 상위 메뉴·시설이 해금됩니다.

## 💾 데이터 저장 및 초기화 안내

- **자동 저장 (`localStorage`)**:
  - 모든 게임 진행 데이터는 서버가 아닌 **사용자의 브라우저 `localStorage`(`pixel_dungeon_inn_save_v1`)에만 저장**됩니다.
  - 5초마다, 업그레이드 구매 시, 그리고 브라우저 탭을 닫거나 숨길 때 자동으로 저장됩니다.
- **오프라인 방치 정산**:
  - 게임을 닫았다가 다시 접속하면 비운 시간(최대 **8시간** 상한)과 초당 골드(GPS)를 계산하여 **「다녀왔습니다!」** 정산 모달을 통해 오프라인 골드를 지급합니다.
- **처음부터 다시 (초기화 방법)**:
  - 상단 헤더의 **`[🔄 초기화]`** 버튼을 누른 뒤 확인 대화상자에서 **`[🗑️ 초기화 실행]`**을 선택하면 `localStorage` 저장 데이터가 삭제되고 처음부터 다시 시작할 수 있습니다.

## 🛠️ 로컬 실행 및 빌드 방법

이 프로젝트는 **Vite + Vanilla TypeScript**로 작성되었으며 런타임 외부 네트워크 의존성 없이 동작합니다.

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 프로덕션 정적 빌드 (dist/ 폴더 생성)
npm run build

# 4. 빌드 결과물 로컬 미리보기
npm run preview
```
